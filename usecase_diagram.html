📋 О системе

Это автоматизированная система для управления заказами на платформе Kwork.ru через Telegram. Система позволяет автоматически обрабатывать входящие сообщения с помощью ИИ (GPT-4) или вручную менеджером, загружать и парсить документы, создавать отдельные топики для каждого клиента и отслеживать весь диалог.

👤 Участники (Actors)

  • Kwork User - Пользователь платформы Kwork
  • Manager - Менеджер, обрабатывающий запросы вручную
  • Admin - Администратор системы

🔵 Основные прецеденты (Main Use Cases)

  • UC1 - Просмотр входящих сообщений от клиентов
  • UC2 - Проверка активных диалогов на Kwork
  • UC3 - Отправка сообщения пользователю
  • UC4 - Автоматическое создание топика в Telegram

🤖 Прецеденты обработки (Processing Use Cases)

  • UC5 - Обработка сообщения ИИ (GPT-4)
  • UC6 - Обработка сообщения менеджером вручную
  • UC8 - Генерация ответа с использованием истории
  • UC7 - Загрузка и обработка прикрепленных файлов

📡 Прецеденты коммуникации (Communication Use Cases)

  • UC10 - Проверка новых уведомлений на Kwork
  • UC11 - Пересылка сообщений в Telegram группу
  • UC9 - Управление режимом (ИИ или менеджер)
  • UC14 - Отметить сообщение как прочитанное

📊 Вспомогательные прецеденты (Support Use Cases)

  • UC12 - Просмотр истории всех диалогов в Telegram
  • UC13 - Извлечение текста из документов (PDF, DOCX и т.д.)

🔄 Ключевые потоки (Key Flows)

  • Диалог → Проверка → Создание топика → Обработка (ИИ или менеджер)
  • Входящее сообщение → Парсинг → Отправка ответа → Пересылка в TG
  • ИИ ответ → История сообщений → Генерация контекста → Ответ пользователю
